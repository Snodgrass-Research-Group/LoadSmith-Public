# MATLAB Bug Register

Bugs found in the original MATLAB code during conversion analysis (2026-07-08).
Each entry records the LoadSmith policy: **fix** (implement the evident intent)
or **faithful-option** (fix by default, but keep a compatibility switch so
outputs can be compared against MATLAB reference CSVs).

The guiding user decision: conversion is **algorithm-for-algorithm** — implement
the *intended* algorithm, not the bugs. Validation against MATLAB reference
outputs must therefore account for each bug below (either by enabling the
compatibility switch or by adjusting tolerance/expectations).
